# Mouse-Aim-and-Shooting

Feature: Mouse Aim \& Shooting



Version: Unity LTS 2022.3.62f2

Scope: beginner - feature prototype



Description:

* The turret block (the character) always rotates to face the mouse cursor. Left-clicking (Mouse 0) fires a spherical block (projectile) that travels toward the mouse position.



Note: no pooling or events for fast development.
